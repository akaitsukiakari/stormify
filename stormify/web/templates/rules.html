How rules work
  1. Every alert lands on the dashboard no matter what. Rules only decide which ones also push to your phone.
  2. A rule matches an alert when Which products and Where both fit. Leave a box empty to mean "any".
  3. Text filters narrow it down after that. An alert that matches a rule but fails its filters goes to the dashboard, with the reason in the feed.
  4. If several rules match, you get one push, at the loudest matching rule's loudness. "Dashboard only" rules never push, so use them to keep things quiet on purpose.
  5. Nothing changes until you press Save. Check against the last 48 h shows what each rule would have pushed. In a rule's editor, Try it sends a test push and lists what the rule matched in the last two weeks.
